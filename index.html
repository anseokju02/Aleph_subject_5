05 · Human judgment

AI와 내 판단 3줄

  1. AI에게 맡긴 일CSV 기능 구현, 고정 검사 자동화, 버전·해시 기록과 인수인계 문서 작성을 맡겼습니다.
  2. 내가 직접 판단한 일브라우저에서 실제 CSV가 내려받아지고 저장값·단위·출처·시각이 맞는지 확인했으며, 두 ZIP과 검사 결과가 같은지 최종 판단했습니다.
  3. AI 제안을 따르지 않은 일추가 기능은 넣지 않았습니다. 고정된 개선 범위를 벗어나면 두 후보의 조건이 달라지므로 CSV 기능과 기존 기능 유지에만 집중했습니다.

06 · Quick verification

재현·통과 확인 4가지

3단계 이내
  1. ① 어디로 가나요?이 공개 비교 보고서의 ‘이름을 가린 실제 비교’와 ‘버전과 소스 일치 증거’ 구역으로 이동합니다.
  2. ② 3단계 이내 무엇을 하나요?두 후보 지표 확인 → 고정 검사 10개 펼치기 → 두 소스 ZIP 중 하나를 내려받습니다.
  3. ③ 무엇이 보이면 통과인가요?두 후보 모두 10/10 PASS, 오류 0회이며 버전 ID와 ZIP 해시가 서로 같으면 통과입니다.
  4. ④ 안 될 때 무엇이 보이나요?검사가 FAIL이거나 ZIP 해시·버전 ID가 다르거나, 판정 구간에 모델·서비스 이름이 보이면 통과하지 못한 것입니다.
